Deploying OnTheWing

Apply the Kubernetes configuration in k8s to your cluster. ArgoCD automatically tracks changes in the OnTheWing repository, and keeps the deployment up to date.

Configuring secrets

Your Kubernetes cluster needs access to the following secrets:

db-credentials
A username and password that OnTheWing uses to authenticate to its postgresql database.
gcp-credentials
A JSON-wrapped key that OnTheWing uses to authenticate to Google Cloud.
gcs-storage-credentials
A JSON-wrapped key that OnTheWing uses to authenticate to Google Cloud Storage.

The Let's Encrypt certificate manager automatically sets the onthewing-tls secret.
