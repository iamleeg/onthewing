Testing OnTheWing

Ensure you have the prerequisites set up, as described in Install Prerequisites . To run the tests in your computer's operating system instead of in a container environment, you also need to install GNUstep's XCTest.

Run Unit Tests

Use this command to run the tests in your computer's operating system: 

        % make check

Use this command to run the tests in the container environment: 

        % make podman-check

Run End-to-End Tests

Use this command to run the tests in a browser in your computer's operating system, with the app running in minikube: 

        % make test-e2e

Use this command to run the tests in a headless browser in the minikube cluster alongside the app: 

        % make test-e2e-cluster
