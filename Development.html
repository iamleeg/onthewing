Running OnTheWing Locally for Development

Install and configure the app's prerequisites. Deploy the app in minikube, and use port forwarding to load the app in your browser.

Install Prerequisites

Install the following packages using your system's package manager, homebrew, or another method:

  • PostgreSQL
  • A container environment, for example, podman.
  • Minikube
  • Skaffold

OnTheWing also depends on the GNUstep Base Library, GNUstep XCTest, GNUstep Web, GNUstep Database Library, node.js, and npm. The build process fetches these and installs them in the app's container.

Start Postgresql

Install postgresql using your system's package manager, or your other preferred method if appropriate. Ensure that your system's service manager, for example GNU shepherd or launchd, starts postgresql automatically, or manually run it at the command-line: 

        % LC_ALL="en_US.UTF-8" /path/to/postgresql/bin/postgres -D /path/to/database/files

If you're setting up PostgreSQL for the first time, you also need to create the database that OnTheWing uses: 

        % createdb onthewing-eedce-database

Start Minikube

Ensure your container environment is running, then start minikube: 

        % minikube start

Minikube automatically configures kubectl to use minikube's cluster as its context.

Start the App

Type the following command to build OnTheWing, deploy the app into the minikube cluster, and forward a port to your host computer: 

        % skaffold dev

When the kubernetes deployment stabilizes, navigate to http://localhost:8080/WebObjects/OnTheWing.woa/0 in your browser to use the local version of the app.
