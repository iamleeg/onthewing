browseJournal 

- (id) browseJournal;
An action an observer calls to browse their nature journal.

capture 

- (id) capture;
An action an observer calls to capture an observation. Observations are "pending" in the Session until an observer reviews them in the ReviewObservations interface, and either deletes them or adds them to their journal.

hasObservations 

- (BOOL) hasObservations;
A Boolean value that indicates whether the observer has pending observations in their Session. Returns YES if there are any pending observations; NO otherwise.

hasUser 

- (BOOL) hasUser;
A Boolean value that indicates whether the Session is associated with an observer. Returns YES if an Observer is authenticated in the Session; NO otherwise.

isAppReady 

- (BOOL) isAppReady;
A Boolean value that indicates whether the OTWApp is ready to receive external requests. This component displays a placeholder UI when this method returns NO.

reportPendingObservations 

- (NSString*) reportPendingObservations;
A string that indicates to an observer whether they have pending observations in their Session.

reviewObservations 

- (id) reviewObservations;
An action an observer calls to review their pending observations.
